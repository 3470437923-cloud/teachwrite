# DeepCompose 代码复审与修复记录

## 范围与基线

本轮检查项目约束、AI 请求/摘要/传输、会话与快照持久化、工具路径授权、回收站及 Rust 文件原语；重点修复已有测试未覆盖的 AI 异常路径。不是全项目无缺陷证明。

修改前：TypeScript 类型检查通过，Vitest 474 例 / 35 文件通过，Rust 19 例通过。

## 已修复

| 问题 | 触发及影响 | 修复与证据 |
|---|---|---|
| 摘要异常后仍被当成有效检查点 | 已收到部分摘要后断流，或上游以输出上限收尾，半截摘要会替代旧上下文；传输抛错则直接打断发送 | `src/core/ai/compress.ts` 同时检查模型完成信号和错误状态；失败不缓存，按现有语义回退完整上下文。断流、缺结束信号、两种截断原因、IPC 抛错的 5 个用例先失败后通过 |
| 监听注册期间停止无效 | `listen()` 尚未完成就调用 `ai_abort`，Rust 还没有请求句柄；随后仍启动网络请求 | `src/core/ai/transport.ts` 保存请求局部取消状态，注册完成后检查；已取消则清理监听并跳过发送。新增用例先失败后通过 |
| 监听注册失败残留活跃请求 | `listen()` 位于 try/finally 外，失败后停止按钮仍会取消过期 ID | 将初始化纳入统一清理路径，活跃状态按当前请求身份清除。新增用例先失败后通过 |

相关优化：停止操作幂等，取消 IPC 的拒绝通过 onError 上报，避免未处理的 Promise rejection。没有新增依赖，也没有改变磁盘格式或配置键。

## 边界

- 网络异常通过传输替身确定性复现，本轮未使用真实 API Key 进行上游测试。
- 修复的停止竞态限于前端监听注册阶段；不声称证明所有 IPC 调度次序下的取消行为。
- 非标准上游如果不发送任何模型完成信号，摘要将被拒绝并回退完整上下文。
- 原有已知边界继续适用，例如跨进程会话索引竞争、生成中途崩溃可能丢失本轮消息、摘要回退完整上下文后仍可能超出模型预算。详见 `KNOWN-LIMITS.md` 与既有修复台账。
