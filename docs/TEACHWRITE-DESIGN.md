# TeachWrite 产品设计

## 产品定位
TeachWrite 是基于 DeepCompose 底层能力的本地优先中文长篇小说人工写作台。正文完全由作者手写；AI 只负责逐场景写作导览、审读意见和小说资料回流。

## 不可绕过的正文边界
- AI 不生成正文、对白、段落、示范写法、仿写或替代句。
- AI 不写入 章节内容/ 与 待确认/ 的正文文件。
- AI 不自动判断导览步骤完成，不自动推进，不自动修改正文。
- 作者的正文编辑器输入是正文唯一来源。

## 核心流程
上一章正文归档完成 → 右侧专用教学入口生成下一章完整导览 → 导览按场景逐步覆盖正文编辑器顶部 → 作者手写并手动勾选 → 点击“审读本章”得到逐项意见 → 作者自行修改 → 按 DeepCompose 机制资料回流并确认归档。

## 兼容策略
- 完整兼容 DeepCompose 作品目录、旧结构、Markdown、快照、日志和回流契约。
- TeachWrite 应用数据独立，identifier 使用 com.teachwrite.desktop。
- 仅在作者触发导览功能时新增 小说资料/写作导览/。

## 三平台
正式目标为 macOS、Windows、Linux，继续使用 Tauri 2 + React + TypeScript + Rust。
