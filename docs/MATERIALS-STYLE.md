# 资料形态契约（MATERIALS-STYLE）

小说资料要便于阅读、检索和维护。优先用短段落讲清故事与因果，只用少量字段记录状态、来源和索引；不把每份资料写成逐项问卷，也不把完整句子压成电报体。

预算和阈值以 `src/core/store/style.ts` 的 `MATERIAL_BUDGETS` / `checkMaterial` 为准。应用打开作品时只做诊断，超标提示不授权自动删除、压缩或改写。预算不是写作目标，也不以模板字符数衡量故事是否完整。

## 文档分工

D-043 起新作品采用新结构（核心 7 件 + 细纲栏目 + 可选追踪模块）；老作品的旧 14 件套原样兼容。同一当前事实只维护一处，其他位置引用即可。正式正文是事实依据；未来大纲和未采用候选明确标为计划，不提前写成已发生的事实。

- `00-项目状态.md` 只放进度、版本、恢复指针与下一步，保留全部既有字段和固定节名（新结构含「启用模块」「当前细纲」行）。
- `01-开书定位.md` 保留开书引导的精确标签及「待填写」整行；已有答案直接使用，补充内容写短段落，不逐项重问。
- `02-核心设定.md` 保留引导使用的时代、机制、核心冲突标签；其余条件与边界写短段落，区分作者真相、人物认识与读者已知。
- `03-全书大纲.md` 用几段连贯文字串起重大变化与结局方向，不重复弧段与逐章细节。
- `04-粗纲.md`（新结构，替代旧 `04-分卷大纲.md`）只有「`## 第N-M章 弧段名` + 一段缩略内容」一种块：弧段目标、主要阻力与弧末新局面，可短到一句话；不写逐场细节。
- `细纲/第N-M章细纲.md`（新结构，替代旧 `05-滚动细纲.md`）每份固定覆盖 3 章，每章约四段自然段（承接与目标 / 主要场面 / 依据与约束 / 变化与章尾）。弧段写完改名为「（已完成）」充当章节摘要（新结构不再单设章节摘要文件）。临近结尾按实际剩余章数。老作品的 `05-滚动细纲.md` 与 `章节摘要.md` 继续有效。
- `06-写作风格.md`（新结构，替代旧 `06-写作规则.md`）只有两节：`## 风格规则` 与 `## 禁用列表`（`- 禁止：…` 一行一条，带来源）。**风格规则**一条一个 `### SR-编号` 块加三行字段——`- 规则分类：`（这条规则服务于哪类内容：视角/节奏/对话/描写/用词…）、`- 规则来源：`（用户指定 / 手改回流·GL-编号 / 学习沉淀·第N章）、`- 具体内容：`；编号只增不复用，一条只讲一件事，文字用自然句不用列表。**2026-10-11 前的自然段格式仍然合法**（老书不迁移照旧读），但新写与整理时按 SR 块格式。通用写作纪律在 novel-writer 技能里，不进作品文件。
- `人物库.md` 每人用自然段写约六方面信息：身份、背景与长期追求；在意之处、缺陷与底线；基本能力边界；关系起点；说话习惯与压力反应；依据及最近更新章节。人物特有的语气与关系差异留在这里，动态状态与资源数量放追踪表。**世界观与情节复述不得写入人物库**（写入校验会拦截/警告）。
- `章节摘要.md` 每章采用后追加几句历史索引，按卷分组，不承担当前值维护（老结构；新结构由已完成细纲接替）。
- 五份追踪表沿用 `## 编号` / `## 人物名` 加 `- 键：值` 的条目结构。保留编号、状态、来源字段及伏笔统计键，不因精简改名、删字段或强制转为单行矩阵；编号只增不复用，废弃条目改状态不删除。
- `个人改稿/规则台账.md` 是候选规则的计数板：GL 编号 + 规则/类别/证据/命中章节数/状态/最近更新；命中 ≥2 章经 question 确认后晋升进 06-写作风格.md。

粗纲给弧段，细纲给当前 3 章；两者矛盾时查已确认方向与正文，不自动宣布某份计划覆盖另一份。远期逐场细节可在授权整理时移到 `小说资料/审核/` 并保留入口。

## 写法

正文默认用自然段讲清故事与因果，只保留节内修改需要的 `#`、`##`、`###` 等 Markdown 标题。只有00状态、01与02开书引导精确字段、五份追踪字段沿用 `- 键：值`。普通大纲、细纲、人物卡、摘要和学习记录不加列表前缀，也不用表格、加粗、引用标记或行内代码装饰。

标题不能改成纯文本：节定位依赖井号标题。开书引导只匹配带短横线的精确标签整行；项目状态读取首个二至六级标题前的字段；伏笔计数依赖 `## 伏笔统计`、`## F编号` 和 `- 状态：值`，这些标记保留。路径原样书写，需要跳转时使用合法 Markdown 链接，不删除路径分隔符和链接语法。原文短引用用中文引号。

不用框线图、emoji或装饰符号、装饰分节线、箭头和加粗，不用斜杠拼接概念。场景篇幅计划（如「约1200字」）可以保留，它指导详略，不属于过程记录。过程记录与设计论证不常驻内容文件，避免反复读取无关信息。

更新用户现有资料优先节内替换、追加条目；用户已经调整的格式优先，不将其强行恢复成新模板。字段数是新模板的简洁写法，不是删去已有事实的依据。

## 存量资料与过程记录

导入说明、核对证据、遗疵和文档去向记录放 `小说资料/审核/<名字>-<日期>.md`；状态入口仅留下一步与必要指针。作品决策记录也留在作品审核归档，仓库实现裁决才放 `docs/DECISIONS.md`。

整理存量资料须有用户授权，写前快照并保留原样归档。按文件核对事实、来源、编号和章节覆盖，远期细节归档后留可检索入口；冲突和未定事项原样保留，不趁整理裁定设定。预算不能触发自动清理，候选未采用不回写事实，个人文风学习仍须用户逐条确认。
