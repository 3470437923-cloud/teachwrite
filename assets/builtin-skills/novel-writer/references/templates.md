# TeachWrite 文档协议参考

正文由作者手写。本文只说明兼容字段与资料结构，不授权 AI 生成、示范、续写或改写正文、对白、替代句；不授权 AI 修改正文文件、勾选导览、推进章节或写归档凭据。

新建作品时应用自动生成核心 7 份文档（00-项目状态 / 01-开书定位 / 02-核心设定 / 03-全书大纲 / 04-粗纲 / 06-写作风格 / 人物库）+ 细纲/ 目录；五份追踪表是**可选模块**，按 00 头部「启用模块」声明创建。老作品（无「启用模块」行）沿用旧 14 件套结构，本文件中两版名称并列时以盘上实际存在的为准。**用户改过格式后，以用户当前文件为准，本参考只用于理解字段含义。**

## 00-项目状态.md 字段协议

头部键值（`- 键：值` 格式，替换值时保留键名）：

| 字段 | 含义与写法 |
|---|---|
| 当前阶段 | 开书准备 / 开书自检 / 连续写作 / 收尾 |
| 当前章节 | 第NNN章（三位数字；下一个要写的章） |
| 启用模块 | 只列启用的追踪模块（伏笔 / 角色状态 / 时间线 / 资源与权限 / 废弃设定）；全不启用写「无」 |
| 最新正式正文 | 章节内容/第N章.md 或 无 |
| 当前细纲 | 细纲/第N-M章细纲.md（进行中）或 无 |
| 当前唯一最新候选 | 待确认/第N章-候选.md 或 无；兼容已有 vX 候选路径 |
| 正文处理进度 | 未开始 / 起草中 / 待逐段修改 / 修改复读中 / 待用户确认 |
| 本次必读 | 按当前任务列 2—4 个文件路径 |
| 下一步 | 一句话，具体到动作 |

固定小节：`## 开书自检`（状态 / 所检材料版本与范围 / 结论位置及未决项；老作品里叫「开书大纲自检」）、`## 最近一次采用回写`（来源章节与采用版本 / 回写状态 / 已更新文件 / 待完成项 / 尚未解决的冲突 / 最近更新时间；老作品里叫「最近一次正式回写」）、`## 约定`。

## 追踪表条目格式

条目一律 `## 编号` 或 `## 人物名` 起头，字段 `- 键：值`。新增条目追加在文件末尾；更新既有条目做节内替换。

- **追踪-伏笔.md**：开头一节 `## 伏笔统计`（`- 开放 / 已回收 / 废弃 / 合计`，值写条数或留「待填写」）+
  条目 `## F001` + 内容与涉及对象 / 首次出现章节 / 当前进展 / 预计触发或回收条件 / 状态（开放|已回收|废弃）/ 来源与最近更新章节。
  **统计是自述，必须与条目数一致**：应用会把统计行与 `## F` 条目数逐项核对，不一致会在作品校验里报 `foreshadow-count-mismatch`。写数字前先数一遍条目，别凭印象填；留「待填写」＝没有自述，不会被核对。
- **追踪-角色状态.md**：`## 人物名` + 当前位置、身体与情绪状态 / 当前目标 / 已知事实与误信信息（分开写）/ 尚不知道的关键信息 / 当前关系与利益 / 来源及最近更新章节
- **追踪-时间线.md**：`## T001` + 时间、地点与事件 / 涉及对象 / 来源及最近更新章节 / 状态（开放|完成|废弃）
- **追踪-资源与权限.md**：`## R001` + 人物或组织 / 金钱、物品、身份、能力或权限 / 当前数量与限制 / 获得来源 / 最近变化及其来源章节 / 最近更新章节 / 状态（有效|耗尽|失去|废弃）
- **追踪-废弃设定.md**：`## D001` + 已废弃内容与涉及对象 / 废弃原因 / 被哪条正式设定替代 / 决定来源 / 生效及最近更新章节 / 禁止恢复：是

编号只增不复用；废弃条目改状态不删除。

## 职责边界（同一事实只维护一处）

| 信息 | 唯一归属 |
|---|---|
| 稳定特征（身份、性格、能力边界、关系起点） | 人物库.md |
| 动态状态（位置、伤势、知情、目标） | 追踪-角色状态.md（启用时） |
| 数量与权限当前值 | 追踪-资源与权限.md（启用时） |
| 历史情节索引 | 已完成细纲（`细纲/第N-M章细纲（已完成）.md`）；老作品是 章节摘要.md（按卷分组，`### 第N章 摘要`） |
| 当前事实的最终依据 | 章节内容/ 正式正文 |

## 细纲与粗纲

- `04-粗纲.md`：弧段级预测。只有 `## 第N-M章 弧段名` + 一段缩略内容这一种块；区间不重叠、按序；不写逐场细节。
- `细纲/第N-M章细纲.md`：每份覆盖 3 章（临近结尾按实际剩余），每章约四段自然段（承接与目标 / 主要场面 / 依据与约束 / 变化与章尾）。头部字段：`- 状态：进行中 / 未启动 / 已完成`、`- 所属弧段`、`- 覆盖范围`。
- 弧段写完：改名为 `第N-M章细纲（已完成）.md`、状态行改「已完成」；采用稿偏离细纲时在文件末尾补 `## 实际与细纲差异` 节（没有偏离不补）。
- 规划第 N 章导览时最小读取：当前细纲 + 上一段已完成细纲（有则读），不回头读全部细纲。

## 候选文件命名

- 兼容作者稿文件名 `第N章-候选.md`。作者通过编辑器手写与修改，AI 不创建、改写或复制此类正文，不另存 AI 版本。
- 旧版 `第N章-v1-初稿.md`、`第N章-v2-候选.md` 等保留兼容，不自动删除；AI 只按任务读取，采用与归档由作者和应用流程处理。00 的既有候选字段只作索引，不是 AI 起草指令。
- 章号用阿拉伯数字（第3章），与 章节内容/ 命名一致

## 个人改稿/ 工作区

`改稿对比-第N章.md`：仅有可复用改稿判断时才记录；没有判断时不创建文件或追加空记录。

```
## <日期> <一句话概括这次改动>
旧版处理：…（不复制用户原句，概括方向）

用户修改方向：…

推断规则：…（说明触发场景、修改方向和边界）

性质：说明属于事实修正、编辑判断还是表达偏好，区分明确原因与推测原因。

晋升状态：未晋升。确认或否决后补充日期与去向。
```

`规则台账.md`：候选规则的计数板。GL 编号只增不复用；同一判断再次出现只补证据、命中章节数 +1，不重复建条。

```
## GL-001
- 规则：一句话（删什么 / 改什么 / 禁什么）
- 类别：词汇 / 句法 / 标点 / 称谓 / 视角 / 节奏 / 其他
- 证据：第3章（「原」→「改」）；第7章（……）
- 命中章节数：2
- 状态：候选 / 已晋升 / 已否决
- 最近更新：YYYY-MM-DD
```

## 06-写作风格.md 节结构

固定两节：`## 风格规则` 与 `## 禁用列表`（`- 禁止：…（来源：用户指定 / 学习沉淀·第N章）`，一行一条）。

`## 风格规则` 里**一条规则一个 `### SR-编号` 块**，块内三行字段：

```
### SR-001
- 规则分类：视角
- 规则来源：用户指定
- 具体内容：第三人称有限视角，通常跟随沈逸；同一段不切换视角。
```

`规则分类`写这条规则服务于哪类内容（视角 / 节奏 / 场景 / 对话 / 描写 / 用词 / 时间 / 意象…），
`规则来源`写它从哪来（用户指定 / 手改回流·GL-编号 / 学习沉淀·第N章）。一条只讲一件事：
同一件事的正反两面可以拆成两条（例如「对话要完整」与「对话不啰嗦」）。编号只增不复用，
正文用自然句不用列表。**2026-10-11 之前的自然段格式仍然合法**，老书不迁移照旧读；
新写与整理时按 SR 块格式。

AI 只允许在用户确认后追加或修改条目；作者指导纪律（导览、审读、资料回流和作者归档）在 novel-writer 技能里，不写进这个文件。老作品里它叫 `06-写作规则.md`，节更多（含「个人文风（学习沉淀）」节），按盘上实际文件工作。

## 资料形态契约（写任何资料前先看；应用会逐份体检并在状态条提示）

正文用自然段讲清故事与因果，不逐项问卷。标题最少保留 Markdown 井号层级，便于节内修改。只有00状态、01与02开书引导精确标签、五份追踪字段保留 `- 键：值`，待填写占位与固定节名不改；伏笔保留 `## 伏笔统计`、`## F编号` 与状态字段。其余不加列表、表格、加粗、引用标记或行内代码装饰。路径原样书写，需要跳转时保留合法 Markdown 链接，不删路径分隔符或链接语法。原文短引用用中文引号。

**禁止**：框线与 ASCII 图（比例字体必然错位、一改就破）、emoji 与 `★◆※` 等装饰符、`---` 分节线（分节用标题）、箭头当连接词（写成「先…再…」）、加粗，以及斜杠拼接概念。指导详略的「约N字」场景篇幅计划可保留，不算过程记录。

**过程记录不进内容文件**：导入说明、核对证据、遗疵清单、文档归位表、施工待办 → `小说资料/审核/<名字>-<日期>.md`；`00-项目状态.md` 的「下一步」只留一行。

**单一职责**：04-粗纲每弧段一个标题加一段缩略内容；细纲每份只覆盖 3 章，每章约四段自然段，分别说清承接与目标、主要场面、依据与约束、变化与章尾。当前细纲只剩 1 章未写时续补下一段（新文件，状态=未启动或进行中），临近结尾按实际剩余章节。远期逐场细节经授权归档并留入口；计划不冒充已发生事实，冲突查已确认方向与正文。

以下技术参考表不作为小说资料的生成模板。

**体量预算（诊断阈值，不是写作目标）**：超标只报告，不授权自动删除、压缩或改写；整理须有用户授权并保留事实、来源与可检索归档。

人物库每人保留一个二级标题，正文用自然段交代身份、背景与长期追求，在意之处、缺陷与底线，基本能力边界，关系起点，说话习惯与压力反应，依据及最近更新章节。
人物特有的语气、关系差异和压力反应留在人物库；06只写全书共用的表达原则。位置、伤势、知情、资源数量写进追踪表。
